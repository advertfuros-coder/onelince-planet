GATEKEEPER Middleware Guard Every request is intercepted at the edge to verify token integrity and role-level path matching.
CONTEXT Header Injection Verified user details (ID, Role, Email) are injected into request headers for downstream logic.

ISOLATION Workspace Sandboxing Roles are strictly decoupled. A seller cannot access admin tools even with a valid session.
SCALABLE Dynamic Scopes Permissions are centrally defined in middleware, making it easy to add new "Staff" or "SuperAdmin" roles.

ENCRYPTION Identity Guard Passwords are hashed using high-entropy Bcrypt salts, ensuring they are never stored in plain text.
PRIVACY Internal Fields Sensitive fields like 'password' are hidden from API responses by default using Mongoose selectors.

⚖️ Security Architecture Comparison

🛒 Basic WooCommerce

Auth: Session-based (Cookies). Harder to scale horizontally.

RBAC: Often relies on plugins that can conflict or cause leaks.

API: Default REST endpoints often expose too much meta-data.

🌍 Online Planet

Auth: Stateless JWT. Perfect for high-traffic marketplace scaling.

RBAC: Native Middleware 'Access Gates' built into the core engine.

API: Strict Field Protection (select: false) to prevent data leak.
